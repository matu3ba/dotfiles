==usage

list WSL OSes: wsl -l
select WSL OS (distribution): wsl -d
change default WSL OS: wsl -s
use shell in WSL: wsl bash script.sh
WSL hex dump .gitattributes: WSL bash cat .gitattributes | od -c | tail

does not work with virtualbox
https://github.com/MicrosoftDocs/WSL/issues/798

wsl --install --no-distribution

cd ~\Documents

curl -JLO https://github.com/nix-community/NixOS-WSL/releases/download/2505.7.0/nixos.wsl
curl -JLO https://github.com/nix-community/NixOS-WSL/releases/download/2505.7.0/nixos.wsl.sha256

sha256sum -c nixos.wsl.sha256

.\nixos.wsl
or wsl --install --from-file nixos.wsl

same system:
sudo nix-channel --add https://nixos.org/channels/nixos-25.05 nixos
sudo nix-channel --add https://github.com/nix-community/NixOS-WSL/archive/refs/heads/release-25.05.tar.gz nixos-wsl

sudo nix-channel --update
sudo nixos-rebuild switch

wsl -s NixOS
