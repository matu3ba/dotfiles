==Example1_ImagePullSecrets
Improvements based on https://kubernetes.io/docs/tasks/configure-pod-container/pull-image-private-registry/.
Requires kind and docker installation.
>{
kubectl create namespace ns-secrets --dry-run=client -o yaml | kubectl apply -f -
kubectl config set-context --current --namespace=ns-secrets
kubectl create secret generic sec-regcred --from-file=.dockerconfigjson=$HOME/.docker/config.json --type=kubernetes.io/dockerconfigjson
kubectl get secret sec-regcred --output=yaml
kubectl get secret sec-regcred --output="jsonpath={.data.\.dockerconfigjson}" | base64 --decode

# option 1: minimal pull test container
kubectl run pull-test --restart=Never --overrides='{"spec": {"imagePullSecrets": [{"name": "sec-regcred"}]}}' --image=IMAGE_REGISTRY:VERSION
# option 2: use test pod bla.yaml
cat > bla.yaml <<'EOF'
apiVersion: v1
kind: Pod
metadata:
  name: bla
spec:
  containers:
  - name: bla-pod
    image: "IMAGE_REGISTRY:VERSION"
    imagePullPolicy: IfNotPresent
  imagePullSecrets:
  - name: sec-regcred
EOF
kubectl apply -f ./bla.yaml
# evaluate
kubectl get pods -A
kubectl logs pull-test
kubectl logs bla
kubectl describe pod bla
}<

=WSL
WSL needs `~\.wslconfig` with `networkingMode=mirrored`. Reasonable defaults are
>{
[wsl2]
memory=8GB                       # Limit memory allocation so WSL doesn't starve the host
guiApplications=false            # Disable GUI if not strictly required to save overhead
networkingMode=mirrored          # Mirrors Windows network stack (fixes VPN/Proxy container bugs), needed for fetching images
vmIdleTimeout=120000             # Auto-suspend idle VM (reduces I/O load)
kernelCommandLine=swapaccount=1  # Safer swap handling

[experimental]
autoMemoryReclaim=gradual     # Automatically drops cached RAM to prevent freezes
sparseVhd=true                # Shrink .vhdx when you free space
}<
