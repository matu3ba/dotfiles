=how_it_works
1. read templates
2. read values.yaml of Chart
3. global test overrides values based on cli flags (helm unittest -v my-test-values.yaml .)
4. test suite > values block overrides in ${file}_test.yaml
5. test suite > set block (it sections) overrides in in ${file}_test.yaml

usage {{ .json_accessor }}
or see =tpl_horror

=syntax: https://github.com/helm-unittest/helm-unittest/blob/main/DOCUMENT.md

only - dashes as seperators are allowed

=tpl_horror
* Named Templates, but actually more horrible than C macros
* needed for helm ecosystem to do dynamic config stuff with loops etc
* needing indenting for unit testing to work, lol
* {{- and -}} are whitespace trimmer, for leftwards/righwards trimming of whitespace and line breaks
* {{ tpl .Values.something . }} forwards strings from values.yaml afterwards through template engine
* nindent for newline indent
* kubernetes conform name example
* basic syntax very incomplete: https://masterminds.github.io/sprig/
{{- $gw := include "envoy-single-gateway.gatewayName" . -}}
{{- $suffix := default "http-to-https" .Values.redirect.name -}}
{{- printf "%s-%s" $gw $suffix | trunc 63 | trimSuffix "-" -}}
* general structure
{{- define "envoy-single-gateway.labels" -}}
{{- include "common.labels" . -}}
{{- end /* include "common.labels" */ -}}
{{- /* required "error message" value */ -}}
{{- required "values.gatewayClass.name is required..." .Values.gatewayClass.name -}}
{{- if .Values.gatewayClass.enabled -}}

{{- else /* if .Values.gatewayClass.enabled */ -}}
  {{- /* block as conditional include guard to add text */ -}}
  {{- with .Values.oidc.redirectURL }}
  redirectURL: {{ . | quote }}
  {{- end }}
{{- end /* if .Values.gatewayClass.enabled */ -}}
{{- end /* define "envoy-single-gateway.labels" */ -}}
