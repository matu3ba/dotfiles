Simplest On-Prem Linux Setup with TPM Integration
does not natively support TPM auto-unseal (HSM/KMS is Enterprise-only) . Workarounds:
    tpm2-tools + systemd unit — seal the unseal key(s) to the TPM's NVRAM at first boot, unseal on start via a systemd ExecStartPre script.
    clevis + tang — clevis pins secrets to TPM2 (PCR-bound unseal key), tang is the network policy server.
    * Works well for auto-unlock without storing keys in plaintext.
    * Most distros package it.
    go-tpm + custom plugin — if you need tight Vault integration and control; more dev work.
  * extra: systemd hardening (NoNewPrivileges, PrivateTmp, etc.)
  * TPM PCR binding can break on firmware/kernel updates → test recovery path. Single-node has no HA.
